# Challenge 03 - Listas enlazadas

Proyecto en React que resuelve el challenge.

## Cómo correrlo

```
npm install
npm run dev
```

## Archivos importantes

- `src/LinkedList.js` -> lista enlazada simple, usada en la página de canciones.
- `src/DoublyLinkedList.js` -> lista doblemente enlazada, usada en la página del navegador.
- `src/PaginaCanciones.jsx` -> página 1, reproduce canciones en orden con el botón "Siguiente".
- `src/PaginaNavegador.jsx` -> página 2, navega el historial con "Atrás" y "Adelante".
- `src/App.jsx` -> cambia entre las 2 páginas.
